Project Overview

This project presents an interactive Power BI dashboard for reviewing POS agent performance and business activity. The dashboard brings revenue, transaction volume, profitability and transaction outcomes into a single reporting view.

The design combines executive-friendly KPIs with visual breakdowns by month, transaction type, agent, location and transaction status.

Dashboard Questions

  • How is revenue changing over the reporting period?
  • How does revenue vary by transaction type?
  • Which agents contribute the most revenue?
  • Which locations generate the most revenue?
  • What proportion of transactions are successful?
